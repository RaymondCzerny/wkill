**The xkill equivalent in Plasma 6 (Wayland)**

Using the standard keyboard shortcut Ctrl+Super+Esc, you get the skull cursor, just like with xkill.

For the command line, it is best to create a Python script that achieves the same effect via DBus. 
If the ‘x’ in xkill stands for X11, the ‘w’ could stand for Wayland. The script could therefore be called wkill.
